Pensarlo como software ayuda: entrada, decisión y salida. El driver existe porque el microcontrolador no puede alimentar motores directamente.

El robot tiene dos dominios de energía.

LÓGICA USB → ESP32 → 3.3 V

GPIO, señales y control.

MOTORES 4 × AA → VM → motores

Corriente y movimiento.

Ambos comparten GND. No comparten la misma carga.
Separar lógica y potencia evita resets y falsas conclusiones. Las tierras deben estar unidas para que las señales tengan la misma referencia.
